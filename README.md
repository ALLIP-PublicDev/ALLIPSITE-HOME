# 올아이피정보통신 홈페이지 - Maxfree 상세페이지 기획 및 개발

본 프로젝트는 올아이피정보통신의 **'Maxfree 8-in-1 충전식 리튬이온 배터리 패키지'** 공식 랜딩페이지(상세페이지) 구축 및 디자인 고도화 작업 내역을 담고 있습니다.

## 🚀 주요 업데이트 및 작업 내역

### 1. UI/UX 및 디자인 전면 개편

- **모던 웹 트렌드 반영:** 가독성을 높인 다크 네이비 텍스트 컬러(`var(--ink)`)와 여백(Padding) 최적화.
- **시각적 계층화:** 클릭 가능한 '버튼(Button)'과 정보 전달용 '태그(Chip)'의 디자인을 완벽히 분리하여 사용자 경험(UX) 개선.
- **반응형 웹(Responsive Web):** PC, 태블릿, 모바일 환경에 맞춰 레이아웃과 폰트 사이즈(`clamp` 함수 활용)가 자동 조절되도록 구현.
- **플로팅 사이드바(TOC):** 우측 하단에 스크롤을 따라다니는 자동 목차 하이라이트 및 카카오톡 상담, 맨 위로 가기 버튼 추가.
- **애니메이션 효과:** 스마트 LED 상태표 영역에 실제 기기처럼 직관적으로 깜빡이는 점멸(Blink) 애니메이션 적용.

### 2. 마케팅 카피라이팅 및 콘텐츠 고도화

- **고객 공감형 스토리텔링:** VR 게이머의 '몰입의 단절'과 부모님들의 '건전지 서랍장 스트레스'를 해결하는 서사 구조 배치.
- **강력한 경제성 어필:** 다이소, 이케아(LADDA), 후지쯔 등 구체적인 경쟁/대체재 키워드를 활용하여 '2500회 재충전'의 가성비를 직관적으로 수치화하여 설득력 강화.
- **숏폼(Shorts) 연계:** 25초 숏츠 영상 임베드 및 리뷰 스크립트를 토글(접기/펼치기) 형식으로 삽입.

### 3. SEO (검색엔진 최적화) 및 메타 태그 강화

- **타겟 키워드 삽입:** `AA건전지`, `AAA건전지`, `충전지`, `메타퀘스트3 배터리` 등 주요 검색 키워드를 Meta tag에 반영.
- **Open Graph (OG) 태그 적용:** 카카오톡 등 SNS에 링크 공유 시 썸네일 이미지와 요약 설명이 예쁘게 노출되도록 설정.
- **JSON-LD 스키마 마크업:** 구글 검색 시 제품 가격(39,000원)과 설명이 눈에 띄게(Rich Results) 노출되도록 구조화된 데이터 추가.

### 4. 구조적 모듈화 (컴포넌트 분리)

- `header.html` 및 `footer.html`을 별도의 모듈 폴더(`/module`)로 분리.
- 자바스크립트 `fetch` API를 사용하여 모든 페이지에서 공통된 헤더/푸터를 일괄적으로 불러오도록 설계하여 유지보수성 극대화.
